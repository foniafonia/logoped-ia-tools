# FonoSuika

Juego de bolas que caen y se funden: cuando dos bolas iguales chocan, se convierten en una más grande.
Va subiendo de fonemas a sílabas y a palabras.

- **Origen:** nació como «Merge Drop» (21 de junio de 2026), a partir de un juego de bolas generado con Higgsfield.
  El 25 de junio pasó a llamarse FonoSuika.

- **Otra versión en línea:** https://fonosuika-775462338032.europe-west2.run.app/
- **Archivos:** `index.html`, `index.js` (juego), `logic.js`, `matter.js` (motor de física) y `demo.mp4`.
