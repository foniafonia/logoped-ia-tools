PROYECTO: ANAMNESIS IA - EVALUACION LOGOPEDICA INTEGRAL PRO

Ubicacion:
- index.html
- README_EXPLICATIVO.txt

Que incluye esta version:
1) Pantalla de intro premium (inicio de anamnesis)
2) Flujo completo de evaluacion por pasos
3) Sidebar con estado de pasos (completo / pendiente / no iniciado)
4) Escalas clinicas 0-3 con etiquetas semanticas
5) Modulo de fonologia (vista mapa y lista de alterados)
6) Denominacion de palabras con imagenes:
   - Vista con imagen por palabra
   - Subida manual de imagen por palabra
   - Reset de imagen por palabra
   - Demo con imagenes incluidas
7) Resumen clinico autogenerado y editable
8) Autosave con restauracion de sesion
9) Informe con graficas (Chart.js)
10) Exportacion PDF basica y PDF completo redisenado

Como abrir:
- Doble clic en index.html
- O abrirlo desde navegador (Chrome/Safari)

Recomendaciones de uso:
- Usa "Abrir demo con imagenes" para ver el flujo completo rapidamente.
- Completa los campos criticos antes de pasar de paso para mejor calidad de informe.
- En paso 4, puedes cargar imagenes reales para denominacion.
- En paso 15, revisa siempre el borrador automatico antes de exportar PDF.

Notas tecnicas:
- El guardado usa localStorage del navegador.
- Si cambias de navegador o limpias datos, la sesion puede perderse.
- Si no ves cambios, haz recarga forzada: Cmd + Shift + R.
