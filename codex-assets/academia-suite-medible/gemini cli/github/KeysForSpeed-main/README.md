**Juego web simple para medir tu velocidad y presición al escribir letras del abecedarios español.**

---

## 🎮 Descripción

*Keys for Speed* es un juego diseñado para poner a prueba tu rapidez y presición la tecla correcta que corresponde a la letra que aparece en pantalla.

- Muestra una letra aleatoria del abecedario español (incluye la 'ñ').
- Tienes un tiempo limitado para presionar la tecla correcta.
- Cada acierto aumenta tu puntaje y aparece una nueva letra.
- Presionar una vocal añade un segundo extra al tiempo restante.
- Presionar una tecla incorrecta o agotar el tiempo terminar el juego.
- Puedes reinciar para intentar mejorar tu récord.

---

## ⚙️ Tecnologías

- HTML5
- CSS3 (archivo externo 'estilo.css')
- JavaScript (vanilla)

---

## 📋 Cómo jugar

1. Carga la página en cualquier navegador moderno.
2. Mira la letra que aparece en grande.
3. Presiona la tecla que coincida con esa letra.
4. Si aciertas, el puntaje sube y aparece otra letra.
5. Si fallas o se acaba el tiempo, el juego termina.
6. Pulse el botón "Reiniciar" para jugar otra vez.
