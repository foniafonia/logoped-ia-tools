🎮 DONKEY KONG FONEMAS

Basado en el Donkey Kong original de Nintendo (1981)

🎯 ¿PARA QUÉ SIRVE ESTE JUEGO?

📚 Objetivo Educativo

Donkey Kong Fonemas es una herramienta terapéutica diseñada para mejorar la discriminación visual de letras similares en niños y adultos con dificultades de lectura.

Combina la diversión del clásico videojuego con ejercicios específicos para distinguir letras que suelen confundirse: P-B-D-Q, M-N-W, b-d, etc.

✅ Beneficios

  • • Mejora discriminación visual
  • • Reduce inversiones de letras
  • • Aumenta velocidad lectora
  • • Refuerza memoria visual
  • • Motivación a través del juego

🎯 Indicado para

  • • Dislexia
  • • Dificultades lectoras
  • • Terapia visual
  • • Aprendizaje de lectura
  • • Refuerzo escolar

🎮 Cómo Funciona

Selecciona una letra objetivo (ej: P). Mario debe esquivar barriles con letras intrusas (B, D, Q) y recoger ítems con la letra correcta. El cerebro aprende a distinguir automáticamente las diferencias sutiles.
