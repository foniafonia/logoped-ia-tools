# Querer Quest

Juego web estático basado en el archivo `17verbo_querer.ppt`.

## Qué es

Una reconversión del material original a formato:

- arcade educativo
- visualmente más potente
- medible
- listo para subir a Netlify o GitHub Pages

## Qué mide

- puntuación
- aciertos
- errores
- precisión
- racha actual y mejor racha
- tiempo medio de reacción
- mejor tiempo
- dominio por tiempo verbal

## Tiempos incluidos

- presente
- pretérito imperfecto
- pretérito perfecto simple
- futuro
- condicional

## Guardado

Guarda sesiones localmente en:

- `localStorage["verbo_querer_arcade_metrics_v1"]`

Y expone la última sesión en:

- `window.__verboQuererMetrics`

## Publicación

Es un proyecto estático. Basta con subir la carpeta tal cual.
