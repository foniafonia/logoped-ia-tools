El problema

Los datos de adherencia desaparecen. "¿Hizo los ejercicios?" "Sí..." → sin registro. Sin datos, sin seguimiento.

5 ejercicios para empezar

Cada uno valida un aspecto clínico diferente. Tú eliges cuál usar según el caso.

1. Repetición con articulación

Apraxia, Disartria

Paciente repite palabra. STT valida si es correcta (ej: "pata").

Validador: Speech-to-Text match + reintentos (máx 3)

2. Control de intensidad

Hipofonía, Voz

Paciente habla "fuerte". Sistema mide dB en tiempo real.

Validador: Web Audio dB (rango 70-90dB esperado) + barra visual

3. Ritmo con metrónomo

Tartamudez, Apraxia

Paciente sigue metrónomo (1Hz). Sistema mide % sílabas "on beat".

Validador: Análisis de pausas + timeline visual de sincronización

4. Apertura bucal + sonido

Apraxia orofacial

Paciente abre boca al vocalizador /A/. MediaPipe + STT validan simultaneidad.

Validador: MediaPipe lip_distance (>20mm) + STT match temporal

5. Variabilidad de pitch + entonación

Dispraxia, Monotonía

Paciente repite frase con entonación. Sistema mide rango F0 (Hz).

Validador: Web Audio FFT + análisis de contorno de pitch (>30Hz esperado)

Honestidad: lo que NO es

Porque la confianza clínica empieza aquí.

No diagnostica

Los números y métricas son feedback, no diagnóstico clínico. "% corrección" ≠ "está bien diagnosticado". Requiere evaluación formal.

No reemplaza al logopeda

Tú diseñas cada ejercicio, tú validas cada sesión. La IA propone, el logopeda decide. Siempre.

Speech-to-Text tiene límites

Con acento, habla muy lenta, o ruido ambiente, STT falla. Requiere validación manual frecuente.

MediaPipe detecta movimiento grueso

No ve asimetría sutil, hipotonía leve, o patrones motores finos. Útil para lo obvio, no para lo fino.

Criterios mal diseñados = ejercicios frustrantes

Si el logopeda define "F0 entre 110-130Hz" en un niño con resfriado, 0/3 intentos validan. Requiere calibración clínica.

Privacidad de menores = crítica

Videos + audios de menores. Cifrado obligatorio, consentimiento dual (padre + menor), acceso auditado.

La regla de oro: Si el logopeda no valida manualmente cada sesión, Logopod Entrenador te puede meter en problemas clínicos reales. Úsalo como herramienta, no como sustituto.

Preguntas frecuentes

¿Necesito equipamiento especial?

No. Solo un smartphone o tablet con cámara y micrófono decente. MediaPipe y STT funcionan on-device o en cloud.

¿Cuánto tarda en implementarlo en mi clínica?

Logopeda: 1-2 horas (conocer la plataforma + diseñar 3-5 ejercicios). Paciente: instalación en 2 minutos.

¿Dónde están los datos?

Cloud seguro (Google Cloud, cifrado at-rest y in-transit). GDPR compliant. Acceso auditado solo para logopeda.

¿Puedo integrar esto en mi app/clínica actual?

Sí. Ofrecemos API + webhooks. Consulta soporte para integración empresarial.

¿Qué pasa si el paciente no mejora?

Es responsabilidad clínica tuya. Logopod es herramienta para medir adherencia y facilitar feedback, no garantiza mejoría. Requiere terapia presencial o supervisión real.
