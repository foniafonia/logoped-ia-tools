# FonoSuika Clip Animador (antes «v2»)

OJO: esto NO es el juego de bolas. Es una herramienta, hecha con React, que convierte un recurso estático
en animación (clips). Rescatada de su despliegue en Google Cloud Run
(https://fonosuika-775462338032.europe-west2.run.app/) por si ese servidor desaparece.

- Es la que se enseña de ejemplo en el curso AELFA («un recurso estático convertido en animación»).
- Autocontenida: no usa claves ni servicios externos (solo las fuentes de Google).
- El juego de bolas que se funden (con motor de física `matter.js`) está en `../fonosuika/`.
- Abrir: https://foniafonia.github.io/logoped-ia-tools/codex-assets/fonosuika-v2/index.html
