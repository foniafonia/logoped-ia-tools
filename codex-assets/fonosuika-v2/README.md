# FonoSuika v2 (versión React)

Segunda implementación de FonoSuika, rescatada de su despliegue en Google Cloud Run
(https://fonosuika-775462338032.europe-west2.run.app/), por si ese servidor desaparece.

- Es la versión que se usa de ejemplo en el curso AELFA.
- Autocontenida: no usa claves ni servicios externos (solo las fuentes de Google).
- La primera versión, con motor de física `matter.js`, está en `../fonosuika/`.
- Jugar: https://foniafonia.github.io/logoped-ia-tools/codex-assets/fonosuika-v2/index.html
