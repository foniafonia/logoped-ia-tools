# DisfagiaCare (Disfagia para novatos)

Aplicación web de una sola página para la disfagia: sistema de recetas adaptadas.
Se enseñó en el CARE Melilla.

- **Versión en línea (Netlify):** https://disgafiaparanovatos.netlify.app
- **Esta copia (GitHub Pages):** https://foniafonia.github.io/logoped-ia-tools/disfagiacare/index.html
- **Panel de Netlify (solo con sesión):** https://app.netlify.com/projects/disgafiaparanovatos/overview
- El archivo es idéntico al publicado en Netlify (salvo un comentario que Netlify añade al servirlo).
- Dependencias externas: Tailwind (CDN), Font Awesome (cdnjs) y una imagen alojada en Poe.

> Herramienta de apoyo. No sustituye la valoración clínica de la disfagia.
