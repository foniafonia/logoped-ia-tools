# 🚀 Desplegar Academia Telegram en Vercel (2 minutos)

## Opción 1: MÁS FÁCIL - Netlify Drop

1. Ve a: https://app.netlify.com/drop
2. Arrastra y suelta el archivo `telegram-academy-standalone.html`
3. ¡Listo! Te da un URL público al instante ✅

**Ejemplo de URL que obtendrás:**
```
https://tu-academia-telegram.netlify.app
```

---

## Opción 2: Vercel (más profesional)

### Paso 1: Descarga el repo
```bash
git clone https://github.com/foniafonia/logoped-ia-tools.git
cd logoped-ia-tools
```

### Paso 2: Instala Vercel CLI
```bash
npm install -g vercel
```

### Paso 3: Deploy
```bash
vercel
```

Sigue las instrucciones interactivas:
- Login con GitHub
- Elige el proyecto
- Confirma

**¡Listo!** Te da un URL público como:
```
https://logoped-ia-tools.vercel.app
```

---

## Opción 3: GitHub Pages (GRATIS, sin CLI)

1. Ve a tu repo en GitHub:
   ```
   https://github.com/foniafonia/logoped-ia-tools
   ```

2. Settings → Pages → Source → `main` branch

3. Sube solo `telegram-academy-standalone.html` a la raíz

4. ¡Accede a:**
   ```
   https://foniafonia.github.io/logoped-ia-tools/telegram-academy-standalone.html
   ```
