# Revision Codex

Este archivo lo usa Codex para auditar el trabajo que Claude reporte en `coordinacion/estado-claude.md`.

Codex no construye el juego en `src/` dentro de este flujo. Su papel aqui es revisar:

- si el encargo se cumplio,
- si el cambio parece coherente con `BIBLIA.md` y `CLAUDE.md`,
- si hay riesgos o partes conectadas que convenga mirar con Graphify,
- si falta probar algo.

## Formato sugerido

```markdown
### Revision del Encargo #N
- Veredicto: aprobado / revisar / bloqueado
- Lo que mire con Graphify:
- Riesgos:
- Pruebas recomendadas:
- Resumen para Idan:
```
