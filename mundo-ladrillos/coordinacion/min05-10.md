## NUEVO — cámara cinemática PORTÁTIL (para el orquestador)
Extraje el "a veces el audio manda sobre el juego" a un helper reutilizable:
`src/scenes/min05/props/CinematicCamera.ts`. Es autónomo (solo Three.js) y sirve
igual para mi preview que para tu ORQUESTADOR del juego completo — así el gag del
avión y los planos de revelado NO se pierden al integrar.

API mínima (engánchalo a tu bucle):
```ts
const cineCam = new CinematicCamera(camera);
ctx.cameraFocus  = (t, s)        => cineCam.focus(t, s);          // seguir objeto (avión)
ctx.cameraReveal = (f,t,lf,lt,s) => cineCam.reveal(f, t, lf, lt, s); // travelling revelado
// cada frame:
if (!cineCam.active) miControlador.update(dt);   // congela input mientras hay cine
escena.update(dt);                                // la escena SIEMPRE avanza
if (!cineCam.update(dt, jugador.x, jugador.z)) miCamaraNormal.update(jugador);
```
- Escenas con revelado de entrada (`Min05Scene.intro`): 9 (río→Jericó→Yehoshúa) y
  11 (murallas). Dispáralo con `cameraReveal(intro.from, intro.to, intro.lookFrom,
  intro.lookTo, intro.seconds)` al montar la escena.
- Gag del avión (esc. 14): al pulsar la treta hago `cameraFocus(avión, 2.4)` + subo
  el clip `m0510_14_avion`; la cámara enseña el avión sola y luego vuelve a manual.
